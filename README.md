# 🇹🇷 Türkçe Quest — турецкий в игровой форме

Веб-приложение (PWA) для изучения турецкого языка. Ставится на Android как обычное приложение.

## Как это работает
- **Путь из 9 уроков**: приветствия, вежливость, знакомство, числа, кафе, город, семья, время, чувства.
- **Типы заданий**: новая фраза, выбор перевода, «как сказать по-турецки», аудирование, сборка фразы из слов.
- **Проверка произношения после КАЖДОГО задания** — кнопка «Дальше» разблокируется только когда фраза произнесена правильно (распознавание речи `tr-TR` + сравнение с эталоном, порог 75%). Ошибки подсвечиваются по буквам, после 2 попыток — подсказка, после 3 — медленная озвучка.
- **Монеты 🪙**: за ответы, произношение (бонус за первую попытку и за точность ≥90%), комбо, прохождение урока и «без ошибок».
- **Магазин знаний**: бонусные уроки-паки (Такси, Базар, Сленг, AI-креатор, Комплименты), карточки грамматики и культуры, бустеры (заморозка серии, x2 монеты).
- **Уровни и ранги** (от Туриста до Султана), **серия дней 🔥**, **достижения**, личный словарь с озвучкой.
- **Сохранение места в уроке 💾**: можно выйти или закрыть приложение в любой момент — урок продолжится ровно с того задания. Начать урок с нуля — отдельной кнопкой «🔄 Начать заново» (с подтверждением).
- **Реферальная программа 🎁**: кнопка «Пригласить друга» отправляет личную ссылку. Друг получает +50 🪙 на старте, проходит первый урок и в один тап отправляет пригласившему ссылку-подтверждение. Тот открывает её и получает **+100 🪙** (один раз за каждого друга, ссылка защищена подписью).
- Прогресс хранится на телефоне, работает офлайн (кроме распознавания речи — ему нужен интернет).

## Запуск на Android
1. Включи GitHub Pages: репозиторий → **Settings → Pages → Build and deployment → Source: Deploy from a branch** → выбери ветку и папку `/ (root)` → Save.
2. Через 1–2 минуты открой в **Google Chrome** на телефоне: `https://goydin31-creator.github.io/my-first-project/`
3. Меню Chrome **⋮ → «Установить приложение» / «Добавить на главный экран»**.
4. Разреши доступ к микрофону при первом задании.

> Если турецкая озвучка молчит: Настройки Android → Синтез речи → Google → Установить голосовые данные → Türkçe.

## Большой разговорник «Турция по объявлениям»

Коллекция `CLASSIFIEDS` в `src/data.js` — один большой разговорник, разбитый на **7 категорий** (~100 слов): разделы сайтов объявлений, недвижимость вплоть до м², авто, товары, слова объявлений, услуги/работа и аккаунт/настройки приложения. Каждая категория проходится как обычный урок (произношение, монеты, звёзды, сохранение места).

Там же — **диалоги** (`CLASSIFIEDS.dialogs`): мини-разговоры, где в своей реплике нужно **вставить пропущенное слово** (вписать или выбрать подсказку, набор без турецких букв засчитывается), а затем **произнести фразу вслух** с проверкой. Новые категории/диалоги добавляются как элементы массивов `sections` и `dialogs`. Всё бесплатно; открывается на «Пути» и в «Магазине» по карточке → экран выбора категории и диалогов.

## Премиум-уроки и промокоды (заработок без сервера)

Премиум-уроки (недвижимость, бизнес, экстренные ситуации) открываются **промокодом**, который автор продаёт через свои каналы. Проверка кода идёт **офлайн** (подпись), сервер не нужен.

- Пользователь вводит код в «Магазин → 💎 У меня есть промокод» или в «Профиль → Ввести промокод». Также работает ссылка `?promo=КОД` — открыл и премиум активировался.
- Код формата `TQ-XXXX-XXXX`, активируется один раз на телефоне.
- **Генератор кодов** для автора: страница `promo.html` (нигде не связана с приложением, под паролем). Там выбираешь, что открыть, и сколько кодов сгенерировать.
- Коды бывают: на отдельный пак (realty / business / emergency) или `ALL` — весь премиум сразу.

> ⚠️ Защита «бытовая»: один код можно активировать на нескольких телефонах (офлайн это не проверить), а секрет подписи лежит в коде. Для строгой защиты и подписок — сервер (Firebase), когда дойдут руки.

## Разработка и сборка (защита кода)

Исходный **читаемый** код лежит в папке **`src/`** (`src/app.js`, `src/data.js`).
В корне `app.js` и `data.js` — это **обфусцированная** (запутанная) сборка, которую раздаёт сайт. Руками её не правят.

Правило: меняем только файлы в `src/`, затем собираем:

```bash
npm i -g javascript-obfuscator   # один раз
node build.js                    # пересобрать обфусцированные app.js / data.js
```

`build.js` берёт код из `src/`, запутывает его и кладёт в корень. Глобальные имена функций при этом сохраняются (их вызывают inline-кнопки), запутывается внутренняя логика, строки и числа.

> ⚠️ Обфускация затрудняет чтение кода на сайте, но не делает его полностью секретным: браузеру всё равно нужно его выполнить. Пока репозиторий публичный, читаемый исходник доступен в `src/`. Полностью закрыть код — только приватным репозиторием (GitHub Pro или перенос хостинга на Cloudflare Pages).

## Файлы
- `index.html`, `styles.css` — интерфейс
- `src/app.js` — игровая логика (читаемый исходник; в корне — обфусцированная сборка), распознавание и оценка произношения
- `src/data.js` — все уроки, карточки знаний, достижения (легко добавлять новые)
- `manifest.webmanifest`, `sw.js`, `icons/` — установка как приложение и офлайн-режим
